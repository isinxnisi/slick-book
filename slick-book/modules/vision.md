## content/vision.md

### 🎯 「コンテンツ」機能によって実現したいこと（ビジョン）

---

### 1. 情報整理の「新しいスタンダード」の確立
- 表・グラフ・図解といった既存の視覚的表現を超えた、体験型・多軸的な情報提示を可能にする。
- 特定の視点（カテゴリ・時系列など）に固定されない構造により、ユーザー自身が視点を切り替えて情報を理解・探索できる体験を目指す。
- 例：体験や関心度に応じて再構成される図解、ナレッジマップ。

---

### 2. インタラクティブで立体的な情報表現の導入
- ユーザーが操作・選択・探索しながら情報を受け取るインタラクティブな仕組みを取り入れる。
- 表示モードの切替、ステートフローに応じた表示、条件分岐型図解など。
- 長期的には、3次元的・多軸的な情報空間としてのコンテンツ設計を視野に入れる。

---

### 3. 高柔軟性CMSの実現
- コンテンツの構造・状態・表示を定義できるmetaスキーマを軸に、汎用的かつジャンルを問わないサイト管理システムを構築。
- 表現形式（カード／表／マップ）や状態（下書き／公開など）、利用文脈（教育／レビュー／体験共有など）を分離・定義できる構成とする。

---

### 4. 多様な表現を手軽に構築できる制作環境の提供
- 表・グラフ・図解・インタラクティブチャート・分岐型ストーリーなどを、ノーコードまたは低コードで編集・展開可能な仕組みを提供。
- 開発者でなくても、新しいタイプのUX重視型コンテンツを作成・運用できることを目指す。

---

### 🔁 連携すべき仕組み（周辺設計）
- 状態遷移モデル（オートマトン）
- DSLベースの構造定義
- metaスキーマとの統合（項目定義、表示モード制御、文脈タグなど）

---

このビジョンをもとに、次フェーズでは DSL設計、スキーマ設計、UIモジュール設計などを具体化していく。

---


### メモ（元々のテキスト）

#### 「コンテンツ」機能の実装により実現したい事

１、体験を用いて情報の整理軸を多軸化（品質強化）
- 既存観点による１軸ごと静的に整理された情報提供の形式が定型化している中、
　UXを用いて多軸的な整理（ナレッジ＋体験）を促す事で、提供する情報品質の強化を狙う。
　目標としては、新しいスタンダードの一つと認知されるレベルでの品質向上を目指す（要深堀）

２、情報提供サイトとしてのＵＸ向上（競合する情報提供サイトとの差別化）
- サイトへの滞在時間やファンの獲得のため、訪れた閲覧者がつい遊んでしまう／興味を持ってくれるような
　ミニゲームやギャラリーなどといった様々なコンテンツを比較的手軽に用意できる機能を構築する。

３、サイトのカスタマイズ性の向上
- サイトのカスタマイズ性能を段階的に高めていく事で、取り扱うジャンルや目的を限定しない自由度の高いサイト管理CMSを目指す。

### コンテンツ作成例

```
[ Widgets ]
├ パズルチャレンジ (widget/game, WidgetGameStrategy)
│   └ 設定:
│       - クリア条件（スコア閾値やパターン一致）
│       - タイム制限（秒）
│       - ボーナスポイント倍率
│       - UI テーマ選択
├ デイリークイズ (widget/quiz, WidgetQuizStrategy)
│   └ 設定:
│       - 問題文リスト（JSON 配列）
│       - 選択肢（キー→ラベルのマップ）
│       - 正解キー
│       - 回答制限時間（秒）
├ 時系列チャート (widget/chart_dynamic, WidgetDynamicChartStrategy)
│   └ 設定:
│       - 指標キー（例：売上、訪問者数）
│       - 表示期間（開始／終了日）
│       - グラフ種別（折れ線／棒グラフ）
│       - カラー設定
├ 会社成長チャート (widget/chart_static, WidgetStaticChartStrategy)
│   └ 設定:
│       - データポイント（固定 JSON）
│       - ラベル配列
│       - 軸タイトル
├ 製品ギャラリー (widget/gallery_dynamic, WidgetDynamicGalleryStrategy)
│   └ 設定:
│       - 画像 ID リスト
│       - 表示順序
│       - サムネイルサイズ
│       - フィルタ条件（タグ、カテゴリ）
├ ポートフォリオハイライト (widget/gallery_static, WidgetStaticGalleryStrategy)
│   └ 設定:
│       - 画像パスリスト
│       - キャプションテキスト
│       - レイアウト列数
└ デイリー占い (widget/fortune, WidgetFortuneStrategy)
    └ 設定:
        - 占いタイプ（星座、血液型 など）
        - 表示メッセージ（JSONマップ）
        - 配信スケジュール

[ Series ]
├ 製品シリーズ (series/manual, SeriesManualStrategy)
│   └ 設定:
│       - 含める記事 ID リスト
│       - 表示順序
│       - シリーズタイトル・説明文
└ タグ系列 (series/auto, SeriesAutoStrategy)
    └ 設定:
        - 対象タグキー
        - 最大記事数
        - 並び順（新着順／ランダム）

[ Collections ]
├ おすすめ製品 (collection/static, StaticCollectionStrategy)
│   └ 設定:
│       - アイテム ID リスト
│       - OG/Twitter 用画像・説明
│       - ソートキー
└ 春キャンペーン (collection/dynamic, DynamicCollectionStrategy)
    └ 設定:
        - フィルタ条件（開始日／終了日／タグ）
        - 最大表示件数
        - レイアウトタイプ

[ Pages ]
├ 会社概要 (page/basic, SimplePageLayoutStrategy)
│   └ 設定:
│       - 本文（HTML）
│       - SEO タイトル／ディスクリプション
└ お問い合わせ (page/contact, ContactFormPageStrategy)
    └ 設定:
        - フォーム項目定義（JSON）
        - 送信先メールアドレス
        - 完了メッセージ
```
